# LSY Game Projects

这里用于保存我的游戏项目资料，并提供可在手机浏览器中打开的试玩版本。

## 合成进化

在线试玩：

https://lsy-game.github.io/my-game-backup/

完整项目备份包：

`backups/合成进化全部内容.zip`

网页试玩包：

`backups/合成进化-Web试玩包-clean.zip`

## 说明

- `docs/` 目录是合成进化的 WebGame 试玩版，适合发布到 GitHub Pages。
- `backups/合成进化全部内容.zip` 是完整项目资料，适合备份和后续继续开发。
- 当前备份包中没有 Android `.apk`、iOS `.ipa` 或 `.aab`，所以它不是直接安装到手机的安装包。
- 如果想让玩家最方便地体验，推荐使用上面的在线试玩链接。
- 如果之后要发布手机安装版，Android 需要导出 `.apk`，iPhone 需要 TestFlight 或 App Store。

## GitHub Pages 设置

如果在线试玩链接还打不开，需要在 GitHub 仓库页面开启 Pages：

1. 打开仓库 `Settings`
2. 左侧找到 `Pages`
3. `Build and deployment` 选择 `Deploy from a branch`
4. `Branch` 选择 `main`
5. 文件夹选择 `/docs`
6. 点击 `Save`

保存后等待 1 到 3 分钟，再打开在线试玩链接。
