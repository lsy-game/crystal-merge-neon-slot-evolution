# 麦穗小镇 Unity 原生导入包

这个目录现在按 Unity 原生 UI/脚本方案组织，不再使用网页启动器。

## 快速运行

1. 用 Unity 2022.3 打开 `麦穗小镇_Unity工程`。
2. 打开场景：

```text
Assets/Scenes/WheatTownBootstrap.unity
```

3. 点击 Play。

场景内对象 `麦穗小镇NativeGame` 会在运行时创建原生 Canvas、登录页、小镇主场景、背包、任务、收获小游戏和设置弹窗。

## 已包含的原生功能

- 登录页：账号/密码、协议勾选、游客登录、账号不存在提示。
- 小镇主场景：6 块农田、面包房、乳品间、米娅小屋、老汤姆小屋、收获台、公告栏。
- 生产链闭环：种小麦 → 成熟 → 收获入仓库 → 面包房加工 → 任务提交。
- 居民委托：米娅、老汤姆各有一个可提交委托，好感度可增长。
- 背包页：作物、加工品、材料、收藏进度以 4 列网格展示。
- 任务页：田园订单、居民委托、日程路线、图鉴入口。
- 收获小游戏：从小镇收获台进入，使用“收获/获得/奖励/互助能量”表述。
- 设置弹窗：音乐、音效、音量、协议入口占位。

## 美术规格

- 逻辑分辨率：`430×932`。
- 物理规格：`1290×2796 @3x`。
- 画风：暖色手绘田园休闲经营。
- 主色：深绿、奶油白、羊皮纸、金色、木色、橙色按钮。
- 新增 V2 素材位于：

```text
Assets/WheatTown/Art/Images/native-v2/
```

## 场景生成

如需重新生成场景，使用 Unity 菜单：

```text
WheatTown/Create Native Game Scene
```

这会重新创建 `Assets/Scenes/WheatTownBootstrap.unity` 并绑定所有 Sprite。

## 注意

旧网页原型文件可能仍保留在 `StreamingAssets` 作为历史备份，但当前场景不引用它，也不会调用 `Application.OpenURL`。
