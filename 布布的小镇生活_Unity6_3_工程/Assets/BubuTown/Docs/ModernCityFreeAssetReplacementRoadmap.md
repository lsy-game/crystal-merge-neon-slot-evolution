## Quality Gates For Any New Free Package

- Use URP-compatible Lit/Simple Lit materials after import.
- Texture filtering must be Trilinear, anisotropic level at least 8, mipmaps enabled, and no point-filtered albedo maps.
- Public GitHub builds must not include copyrighted IP characters, brand marks, or private local skins.
- Keep private local-only experiments under ignored paths such as `Assets/PrivateSkins/`, `Assets/Characters/LocalOnly/`, and `Assets/Art/IP_References/`.
- Imported assets must pass `ImportedCityAssetQualityReport.md` and the preview anomaly report before being treated as usable.
