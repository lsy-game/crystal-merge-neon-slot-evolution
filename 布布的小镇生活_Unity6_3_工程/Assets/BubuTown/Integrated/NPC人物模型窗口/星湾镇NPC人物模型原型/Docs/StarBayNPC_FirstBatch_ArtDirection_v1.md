# 星湾镇首批 NPC 美术方向 v1

## 小镇管理员

- 角色气质：亲切、可靠、清爽，是玩家进入星湾镇后第一个可信赖引导者。
- 视觉关键词：浅蓝外套、白衬衫、深蓝下装、胸牌、文件夹。
- 功能定位：欢迎剧情、任务引导、买房流程前置说明。

## 星湾旅店前台

- 角色气质：温柔、成熟、安稳，有小旅店前台的舒适感。
- 视觉关键词：奶油色衬衫、暖木色马甲、柔软领结或围巾、房卡钥匙。
- 功能定位：旅店登记、买房前睡觉、存档/换装教学。

## 奶油星球蛋糕店老板

- 角色气质：活泼、甜美、干净，不做幼态玩偶感。
- 视觉关键词：粉白制服、粉色围裙、头巾/发带、蛋糕托盘、裱花袋。
- 功能定位：第一份蛋糕店兼职、送蛋糕任务、早期核心好感 NPC。

## 后续 Unity 模型标准

- 头身比例接近大蘑菇参考图，不使用矮胖胶囊占位。
- 面部要有清楚眼睛、眉毛、嘴形和发型轮廓。
- 身体结构优先用低模块面和圆润边缘表现，而不是纯 Primitive 拼接。
- 每个 NPC 必须有一个职业识别配饰。
- 正式模型后续目标为 Humanoid，可接 Idle、Walk、Interact 动画。
