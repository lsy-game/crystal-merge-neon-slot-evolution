# Asset Store Modern City Imports

把 Unity Asset Store 下载/导入的现代城市资源放在这里，或保留在资源包默认目录也可以。

接入菜单：

- `BubuTown/Integrate Asset Store Modern City Prefabs`

脚本会扫描：

- `Assets/AssetStoreImported/ModernCity`
- `Assets/AssetStoreImported/ModernCity/ITHappy`
- `Assets/AssetStoreImported/ModernCity/ITHappy/CartoonCityFree`
- `Assets/Cartoon City Free`
- `Assets/Cartoon City`
- `Assets/City Pack - Modular and Tileable`
- `Assets/Modern City`
- `Assets/Modern City Block`
- `Assets/Stylized Buildings Pack`
- `Assets/AssetStore`

找到名字包含 `building`、`tower`、`shop`、`city`、`house`、`road`、`light`、`traffic`、`planter`、`tree`、`fence`、`sign` 的 prefab/FBX 后，会优先按 FBX 模型混合生成到场景的 `18_AssetStore_ModernCity_Integration` 分组中。

当前 Kenney CC0 导入层会放置约 80 个真实模型实例，覆盖高楼外圈、商业街、住宅楼、道路模块和街景细节。

建议下一批高质量免费资源：ITHappy Studios 的 `Cartoon City Free`。官方页面标注为 0 美元、80 个低模城市模型，包含现代建筑、道路、车辆和城市道具。下载需要走 ITHappy/Asset Store 账号流程，导入后放到 `Assets/AssetStoreImported/ModernCity/ITHappy/CartoonCityFree/`，再运行集成菜单。
