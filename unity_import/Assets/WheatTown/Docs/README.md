# 麦穗小镇 · 丰收经营 MVP

一个无需安装依赖的浏览器原型，验证“田园收获 → 稳定获得建材 → 建设城镇 → 完成订单与事件”的休闲经营闭环。

## 运行

直接双击 `index.html`，或在本目录启动任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 已实现

- 5×3田园收获格与固定丰收路线
- 单次10金币收获、风车辅助、丰收篮赠送收获
- 田园“相邻符号连锁生长”机制
- 每日400次有效成长产出，木板/矿石固定比例掉落
- 4座功能建筑与1座田园灯塔
- 建筑升级带来长期小镇收获加成
- 居民礼物、好感和每日祝福
- 互助能量补给、单日小镇互助金
- 最多8小时离线金币收益
- 阶段目标金币补给、连续收获、本地存档
- 田园日程：3个循环订单、10/30/60/100/150次分段奖励
- 每25次收获触发一次双选项小镇事件，奖励只影响局外资源
- 100次形成今日丰收总结，150次开启每日丰收宝箱
- 桌面与手机响应式界面
- AI生成并接入的统一田园美术：场景背景、7种收获符号、5座建筑和居民米娅
- 1290×2796竖屏单画面布局：收获页和城镇页均无滚动、无拖动
- 绿幕美术生产流程：纯绿色母版、色键抠图、边缘去绿溢色、透明WebP接入
- 田园木雕UI边框：收获框、侧栏框、建筑卡框、按钮框、进度框和资源栏框

## 数值验证

运行以下命令可进行长期奖励抽样（第二个参数为轮数，第三个参数为奖励缩放）：

```bash
node tools/simulate.js 1000000 0.386
```

当前百万轮抽样的新手金币长期回收约为92%，满级约为96%；赠送收获与互助能量均已计入。该数据为内部调平指标，不建议作为商店页或前台宣传文案。

## 原型说明

这是约30分钟单次游玩节奏的扩展原型，不包含多主题、多档消耗、流派、付费Buff商店和养老系统。奖励与经济参数集中在 `game.js` 顶部，后续可通过批量模拟继续校准。

推荐以1290×2796竖屏比例运行。其他竖屏分辨率会按比例自适应。

## 商店定位建议

对外定位建议使用“轻松田园经营”“建设小镇”“每日订单”“居民祝福”“丰收路线”等表述。不要在商店标题、截图和宣传文案中使用 SLOT、老虎机、投注、赔付线、RTP、爆奖、保底、提现、兑换等容易造成赌场或换皮联想的词。
