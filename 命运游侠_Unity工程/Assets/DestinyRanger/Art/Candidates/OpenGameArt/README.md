# OpenGameArt Candidates

This folder is for raw or lightly processed OpenGameArt candidate assets only.

Rules:

- Do not reference files in this folder from `DestinyRangerSceneBuilder` or runtime gameplay.
- Prefer CC0 assets. If an asset is not CC0, keep it here until attribution and store-review notes are complete.
- Record source URL, license, download date, and original archive/file name before moving anything toward formal use.
- Formal game assets must be converted into the project art style, cleaned for alpha/edges, and then registered in `Assets/DestinyRanger/Docs/ASSET_PROVENANCE.md`.
- Terrain candidates should focus on solid grass/stone floors and readable platform edges, matching `OPENGAMEART_ASSET_PLAN.md`.
