# 命运游侠 v0.1 首局体验规格

## 目标

首局必须在不打断动作节奏的前提下，让玩家理解四件事：怎么操作、为什么要清房、SLOT 如何改变打法、失败后下一局该改什么。

## 标题与简报

- 首次从标题页开始试炼时显示 `OnboardingPanel`，可开始或以后不再提示。
- 设置页必须提供 `SettingsOnboardingReplay` 入口重新查看 `OnboardingPanel`；该回放使用 `onboardingReplayMode`，按钮显示“返回设置/关闭简报”，不能误启动新对局或改写当前运行状态。
- 简报只讲核心循环：战斗清房、房间奖励、SLOT 共鸣、商店补给。
- `OnboardingAssistLine` 必须提示设置里有辅助模式、自动朝向和自动攻击，降低移动端动作门槛。
- `OnboardingAssistLine` 必须说明 `SLOT` 只影响本局战斗，无真钱付费或现金价值。
- 玩家确认或跳过后保存 `DestinyRanger.OnboardingSeen`。

## 局内教学

- 教学提示必须非强制，不能锁住玩家操作。
- 7 步教学覆盖：移动、攻击三连、清房、靠近 SLOT、启封、继续推进、商店补给。
- `TutorialHint` 必须使用短任务格式：`1/7 移动`、`2/7 三连攻击`、`3/7 清敌开路`、`4/7 靠近 SLOT`、`5/7 启封符文`、`6/7 向右推进`、`7/7 商店补给`，不能再显示“教学 X/7：长句说明”。
- 完成后保存 `DestinyRanger.TutorialCompleted`，重复局不再遮挡视野。
- HUD 目标栏要始终给当前房间目标：清敌、选奖励、启封、商店、精英、Boss 或推进。

## 首局上下文助理

- `FirstRunNudgeText` 只在首局教学未完成、无弹窗、无奖励选择、无 `SLOT` 转动时显示。
- 文案必须短、可执行、和当前状态相关，不能覆盖核心操作按钮。
- 必须覆盖这些卡点：
  - `SLOT` 宝箱出现：提示靠近命运宝箱并点右侧启封。
  - 平台小宝箱存在：提示平台小宝箱能加快启封，可跳上去打开。
  - 商店可交互：低血先回血，状态安全或金币足够时召出奖励 `SLOT`。
  - 首个 `SLOT` 未启动：提示优先攒满命运能量，先拿第一个 `SLOT`。
  - 攻击教学早期：提示长按攻击可连斩，第三段破势更重。

## 失败复盘

- 失败结算必须显示倒下房间、推进百分比、最后一击、主要受伤来源和下局挑战。
- `BuildFirstRunAssistAdvice` 必须根据表现给一条可执行建议：
  - 受伤过多且未开辅助：提示可开辅助模式。
  - 连击过低且未开自动攻击：提示自动攻击或长按攻击。
  - 没启封 SLOT：提示优先攒命运能量和开平台小宝箱。
  - 被 Boss/弹幕/弓手击败且没有极限闪避：提示保留闪避。
  - 其他失败：提示围绕盾/冰/闪避提高容错。

## 人工检查

- 首次开始试炼显示简报；跳过后再次进标题不会重复弹出。
- 设置页点“试炼简报”后能重新查看同一简报，关闭后返回设置页，不改变 `DestinyRanger.OnboardingSeen`、当前对局或今日试炼种子。
- 清除本机数据后，简报和教学状态恢复未读。
- 首局失败时，结算页能看到“操作建议”，不是只显示挑战失败。
- SLOT 简报、符文面板和关于/隐私口径一致：无真钱付费、无现金价值、不接广告激励或联网排行。
