# 命运游侠 v0.1 打击与反馈规格

## 对标目标

移动端动作 Roguelite 的反馈必须形成“输入 -> 起手 -> 命中/释放 -> 奖励”的连续确认。画面、声音、震动和停顿要服务于读招与手感，不能只堆特效。

## 分层反馈

## 震动规则

- `hapticsEnabled` 必须可关闭，并保存到 `PlayerPrefs`。
- `HapticPulse(HapticTier tier)` 是唯一分级入口；旧的 `HapticPulse()` 只作为兼容默认中档。
- `hapticCooldownTimer` 必须对震动节流，避免连击、弹幕或 UI 快速点击造成真机过密震动。
- `HapticTierMinGap` 必须按 Light/Medium/Heavy/Reward 分开节流；Light/Medium 单次，`HeavyHapticEcho` 两段短促震动用于三连破势和受击，`RewardHapticEcho` 三段节奏只用于 Boss、SLOT 和重要奖励，不用于普通攻击。
- 舒适低闪只降低视觉闪白和震屏，不应该强制关闭玩家明确开启的震动；玩家可在设置里单独关闭震动。

## 音频规则

- 试玩版使用程序化音效和轻量循环 BGM，不依赖未授权外部音频。
- 设置页必须提供音效开关、震动开关、总音量、音效音量和音乐音量，并使用约 `1380x1300` 的 `SettingsFrame` 与 `SettingsBadgeContainmentPlate`、`SettingsStatusContainmentPlate`、`SettingsVolumeContainmentPlate`、`SettingsAssistContainmentPlate`、`SettingsControlContainmentPlate`、`SettingsActionContainmentPlate` 分区承载；顶部徽章和状态文本必须通过 `FitHudText(settingsComfortBadgesText, 19, 25)`、`FitHudText(settingsStatusText, 18, 25)` 自适应，状态行只用“辅助/反馈/触控/性能”四行短 token，不能恢复长日志式设置说明。
- `PlaySfx` 必须同时受 `soundEnabled`、`masterVolume` 和 `sfxVolume` 控制。
- 程序化音效必须分层：`sfxSlash` 普通出刀、`sfxHit` 轻命中、`sfxHeavyHit` 破势、`sfxSkillCast` 技能、`sfxBossWarn` Boss 高危、`sfxGateOpen` 房门推进、`sfxPickup` 吸附拾取、`sfxRuneRoll`/`sfxRuneReward` 只用于 SLOT/重要奖励。`MakeLayeredTone` 必须用于重击、受击、技能、Boss 预警、开门和 SLOT 奖励，加入谐波和短噪声冲击；普通出刀/拾取仍保持轻量 `MakeTone`。
- `musicSource` 必须受 `masterVolume` 和 `musicVolume` 控制。

## 命中确认 HUD

- `HitConfirmText` 和 `HitConfirmBackplate` 位于右手战斗区上方，只在攻击或技能实际命中敌人/符文罐时短暂出现。
- `HitConfirmTierText` 只显示“破势 / 强命中”“术式 / 范围命中”或 Boss 专用来源；轻击命中由 `lightHitConfirmCooldown` 节流，只显示“命中”和短力度条，隐藏来源副标题，并通过 `hitConfirmLightHit` 使用更小底板和更低暗底 alpha，避免快速连点时右手 HUD 持续闪烁。`HitConfirmImpactFill` 以短条/中高条/满条区分轻击、技能、破势和 Boss 命中。
- `PulseHitConfirmButton` 是真实命中的二次按钮回弹：普攻/重击回弹攻击键，技能命中通过 `SourceSkill` 回弹对应技能键；它不能在出刀空挥时触发。
- `TriggerHitFrameBeat` 是命中帧节拍入口，负责 `HitStop`、闪白、震屏和必要的 `HitFrameBeatText`；敌人和符文罐命中都必须走这条路径，避免不同目标手感不一致。普通轻击的世界层文字必须受 `ShouldShowHitFrameWorldText` 和 `lightHitWorldTextCooldown` 节流，打击感优先靠命中火花、短停、按钮回弹和合并伤害字。

必须为普通怪补受击身份锚点，真实受击时 `SpawnEnemyHitIdentityFreezeCue` 用弓手弓弦断势、史莱姆压缩、蘑菇帽檐定格这些短线确认“已停手且被打中的是哪类怪”，不依赖血条或文字。这些体块只做低透明环境融合，不得新增碰撞、黄色板、脚底光圈、主角复制残影或遮挡攻击帧。
- 普通怪血条和状态字不能常驻刷屏：`HpBarRoot` 默认透明，`HpVisibleTimer` 只在真实受击后短暂显示，普通怪轻击约 `.48s`、重击/技能约 `.72s`，受击显示 alpha 约 `.46f`；靠近或高危前摇时只可用 `.12f` 左右低透明显示，贴身未受击只保留 `.06f`，精英保持中高透明，Boss 头顶小血条弱化，主要读取 `BossHud` 大血条。`EnemyStatusLabel` 必须把普通怪重击/技能状态压成“破势 / 术式”短 token，轻硬直不显示字；只有精英和 Boss 才显示“破势硬直 / 术式硬直”，普通怪 `EnemyStatusText` 字号约 14、alpha 约 `.42f`，避免小怪群头顶刷成长句。
- 普通怪接地读感必须由 `BuildEnemySceneIntegratedPolish` 补足：`EnemySceneGroundedFootPlantTickL_NoPlate` / `EnemySceneGroundedFootPlantTickR_NoPlate`、`EnemySceneGroundedMossContactChip_NoPlate` 和 `EnemySceneGroundedBackFootBrake_NoPlate` 只能作为低透明小脚点、碎草和刹停短线，把怪物脚下扎在主地板上；不得变成脚底大光圈、攻击预警、碰撞体、黄色板或遮挡主角攻击帧的新前景贴片。
- 空挥不显示命中确认，避免玩家误以为攻击判定成功。
- 轻击、三连破势、技能命中和 Boss 命中必须使用不同文案，颜色统一控制在白、青白和电蓝体系；Boss 命中条也必须使用 `#9FF8FF` 冷青白，不能使用 `#FFD95A` 金黄色，避免战斗中误读为黄色背景板。
- 舒适低闪档下降低透明度峰值，但保留弹出与淡出动效。

## 受击恢复 HUD

- `HurtRecoveryText` 位于左下摇杆热区上方，只在真实受击后短暂出现，不占用中心高危预告或右手按钮区。
- 文案必须包含“受击恢复：短暂无敌”，并根据 Boss、弹幕/远程、商店补给或盾/冰构筑提示下一步动作。
- 玩家死亡、标题页或提示计时结束后必须隐藏。

## 伤害数字降噪

- 普通小怪轻击伤害字必须由 `ShouldShowFloatingDamageText` 节流，并在混战合并后由 `UpdateMergedDamageTextVisual` 清空；Boss、精英、三连破势和技能伤害数字不能被隐藏。
- 已经存在的 `MergedDamageText` 可以继续合并后续强命中伤害，防止连续打同一目标时文字跳断；战斗伤害字只用冷白/青色短字，不能恢复 `CRIT` 金黄大字，金币和 SLOT 奖励才使用金色。

## 高危预告

- `ThreatAlertText` 只用于 Boss、精英、弓手和近战怪即将命中的高危窗口，文案必须包含威胁来源和建议动作；Boss 的长期学习提示不再常驻，改由前摇短词、地面细线和反击窗口 `BossResponseHintText` 短提示承担，不能用居中高危预告常驻占屏。
- `WorldSpaceControlHints` 只允许作为首局早期的短时世界教学层，由 `UpdateWorldControlHintVisibility` 控制：`WorldHintDisplaySeconds = 5.4f`、`WorldHintMaxAlpha = .34f`，玩家移动、攻击、进入战斗、打开弹窗、出现 `SLOT` 或超过早期教学窗口后必须隐藏，避免虚拟按键说明长期贴在地图上造成调试层观感；敌人出现后 `ActiveEnemiesInCurrentArea() <= 0` 不再成立，世界层按键教学必须立即收起。世界层只显示“拖动/攻击/点按三连/跳跃/技能/SLOT”这类短入口，按钮图和文字必须是低透明青白，不允许亮白常驻，也不能把“长按连斩”或“剑气/炎弹/冰环/雷击”四个技能名全部贴在地图里，技能细节由右手按钮和冷却状态承担。
- Boss 攻防节奏必须分清“躲避段”和“输出段”：巨拳、激光、雷阵结束后要显示“反击窗口”，并通过低透明 `BossCounterWindowRing_NoTexturePlate`、`BossCounterWindowAttackArrow_NoTexturePlate`、`BossCounterWindowAttackPath_NoTexturePlate` 和 `BossCounterWindowDpsHint` 指向 Boss；反击环约 `1.34f x .018f`、alpha 约 `.085f`，箭头和路径必须是短青白线，不能变成覆盖角色的亮色长条；`BossResponseHintText` 在窗口期提示贴身第三段或交技能，避免玩家只看到红框却不知道什么时候能打。
- 精英毒圈必须可读但不能糊屏：`ElitePoisonPulse_NoYellowPlate` 必须通过 `IsCleanPrimitiveVfxName` 使用程序细线低透明横向范围线，配合 `ElitePoisonSafeEdge_NoYellowPlate` 和 `ToxicWaveStripe` 标清边缘，不能使用高不透明大绿圈或 `CombatVfxSprite(8)` 面片遮挡角色和平台。精英的 `毒素光环` 状态字只能在玩家进入 `EliteStatusLabelDistance = 4.8f` 内显示，远处必须通过脚底毒圈和精英轮廓识别，避免常驻文字刷屏。
- `TargetCompassText` 是非阻塞导航层，只提示方向和距离；它不能替代敌人头顶意图、地面危险区、`ThreatAlertText` 或 `DamageDirectionCue`。`UpdateTargetCompass` 必须先单独处理战斗目标：屏幕内普通怪、屏幕内普通弓手和屏幕内 Boss 不应常驻底部罗盘，`!highPriority` 时直接 `SetTargetCompass(false, "", Color.clear)` 并返回，只有精英、屏外 Boss/威胁和远距离弓手需要罗盘辅助定位；无战斗或高优先级威胁不存在时，才让 SLOT 宝箱和平台小宝箱接管罗盘。常规罗盘必须收成约 700x48 的短条，Boss 专注模式约 600x42，暗底更淡，不能横跨主角脚下、平台落点或右手按钮。
- 进入战斗房必须给出轻量波次可读性，但不能刷世界大字或黄色背景板：`TriggerRoomEnterCue` 必须调用 `SpawnRoomCombatWaveCue(segment)`，只选当前房最多 3 个存活敌人，用 `RoomWaveEntryLane_NoYellowPlate`、`RoomWaveEnemyEntryPin_NoYellowPlate` 和高威胁 `RoomWaveThreatBracket_NoYellowPlate` 标记敌人脚底/头顶短线，普通房约 `.13-.14s`、Boss 房约 `.20-.22s` 内消失；这只是“当前房有怪”的短确认，不能替代敌人前摇、锁门规则或清房目标。
- 清房开门后由 `SpawnProceedRouteCue` 补充推进确认，`ProceedRouteFootGuideLine_NoYellowPlate` / `ProceedRouteArrow_NoYellowPlate` / `ProceedRouteFootTick_NoYellowPlate` / `ProceedRouteDestinationPin_NoYellowPlate` / `ProceedRouteHudOnlyHintTick_NoYellowPlate` 只持续短时间，主线约 `.28f x .004f`、alpha 约 `.012f`，箭头只保留 1 个短针；玩家离门较远时还要由 `SpawnGateOpenPlayerRouteCue` 从脚底补一组无文字、低透明的向右路线，避免玩家把刚打开的门误判为空气墙。清房目标切换时 `SpawnRoomObjectiveProceedRouteCue` 也必须使用 `RoomObjectiveProceedDestinationPin_NoYellowPlate` 和 `RoomObjectiveHudOnlyHintTick_NoYellowPlate`，不能留下无后缀世界层针点。世界层不再弹“向右 / 宝箱可选”推进字，完整房名和原因放在顶部短 Notice 与目标栏。撞门时不生成世界文字，只允许 `LockedGateBumpEdgeTick_NoYellowPlate` / `LockedGateGroundSealPulse_NoYellowPlate` 做极短边界确认；如果最近阻挡敌人已经在玩家身后，Notice 必须改成“门未开 · 回头清敌”，避免玩家误以为前方是空气墙；如果玩家已经顶到门边且阻挡敌人明显落在身后，`GateEdgeSoftUnlockShouldCatchUp` 必须把旧房间段追上，允许继续向右，避免“角色有跑步动作但位置出不去”；门体和箭头都必须低透明，门上动态短字只显示“清敌 N”，顶部 Notice 用“门未开 · 清敌 N”，并由 `ShouldShowNoticeInCombat` 放行，不能把“清掉本房敌人 X 后前进”这类整句贴在门上；如果上一房仍有平台小宝箱，`UpdateProgressGate` 必须写出“上一房小宝箱可选，不锁路，继续向右”，并由 `CompactNoticeCopyForHud` 保留“小宝箱可选，不锁路，向右推进”，避免玩家误判为空气墙或必开箱目标。平台小宝箱提示必须根据高度区分“攻击开箱”和“跳上打箱”，避免固定文案误导玩家。
- 主地板必须像完整横版关卡块，而不是背景前的一条线：`BuildMainSolidGroundFloor` 必须调用 `BuildMainGroundAdventureCrossSection()` 和 `BuildMainGroundAdventureBlockSegments()`，在整条行走层上补 `AdventureMainGroundCartoonTopGrassCrown_NoCollision`、`AdventureMainGroundCartoonSolidSoilFace_NoCollision`、`AdventureMainGroundCartoonStoneBelly_NoCollision`、`AdventureMainGroundPlayableMass_UnbrokenNoBackgroundLeak`、`AdventureMainGroundPlayableGrassCrownContinuous_NoCollision`、`AdventureMainGroundPlayableFrontBlock_NoCollision_*`、`AdventureMainGroundRoundedStoneBlock_NoCollision_*`、`AdventureMainGroundFrontGrassBlade_NoCollision_*` 和 `AdventureMainGroundHangingRootThread_NoCollision_*`，形成草冠、土层、石肚、分段石块、草叶和根须的连续横截面；`BuildMainGroundAdventureBlockSegments()` 还必须调用 `BuildMainGroundStorybookStoneRhythm()`，补 `AdventureMainGroundStorybookStoneCell_NoCollision_*`、苔藓缝、深土断面和根口袋，让主地板前脸有类似横版童话关卡的石砖节奏。这些都是视觉层，不新增碰撞，不允许出现黑线、透明漏底或一整块无细节色板。玩家脚下的主地板必须全段覆盖，不能只在局部靠平台贴图补救。
- 路线需要有童话横版地标，而不是只有背景和平台：`BuildAdventureRouteStorybookLandmarks` 必须补小蘑菇屋、碎篱笆、树桩、树根拱、断桥碎石和符文灌木等低透明 `NoCollision` 地标，用来形成类似《冒险王》一类横版场景的村庄/森林/遗迹记忆点；这些地标不得包含文字，不得使用 UI 面板式矩形牌，不得作为碰撞体，也不能遮挡主角、敌人、宝箱和右手按钮。通用地标必须覆盖开局、中央和 Boss 路径，特殊路线还要分别有森林蘑菇屋、树冠根拱、断桥碎石和符文灌木，保证不同地图不只是平台排列变化。每套路线还必须通过 `BuildLayoutThemeGroundStoryLayer` 增加独立低位故事层：森林用碎篱笆、草垛和蘑菇路径，树冠用根脚和落叶，断桥用低矮碎石和旧篱笆，符文岭用小方尖碑和符文碎石；这些只允许做脚边环境，不得抬成可踩平台，也不得生成碰撞。每套路线还必须通过 `BuildLayoutThemeMidgroundStoryBackdrop` 增加中景轮廓层：森林远村屋顶、树冠小屋、断桥残拱、符文远柱要退在玩法层之后，作为地图记忆点，不得遮脚、遮怪、遮宝箱或形成可踩误读。相反，断桥绳索、树冠悬根、高位符文晶体、符文雾线等“空中/半空”元素必须明显离开地板和低台，不能贴着主角脚下或平台边缘。
- 每套路线还必须有连续但克制的脚边记忆层：`BuildAdventureRouteFootlineMemoryLayer(parent, layout)` 生成 `AdventureRouteMemory_UniversalGrassRhythm_NoCollision`，并按主题追加森林小蘑菇/旧篱笆、树冠根脚/落叶、断桥碎石/旧木板、符文碎片/冷色尘点。这些对象只能贴在地板前缘做横版路线节奏，不得包含文字、不得生成碰撞、不得遮挡主角脚底、不得变成平台顶边或可交互高亮。
- 半空路线提示必须明显高于脚边地标、低台和主角头顶：`RoomRouteClimbHint_CanopyA/B/C_NoCollision` 和 `RoomRouteRuneHighTrail_A/B/C_NoCollision` 最低不得低于 `GroundY + 6.70f`，树冠提示应在 `GroundY + 6.92f~7.15f`，符文高位轨迹应在 `GroundY + 6.88f`；这些只做上方空间层次，视觉上要挂在平台上方而不是贴着地板，不能像可踩平台、不能生成碰撞或黄色引导条。
- 房间路线和地面可读性提示只能像环境纹理，不能像脏框或可交互物：`BuildRouteClimbHint`、`BuildRouteGapEdgeStones`、`BuildRouteRuneHighTrail`、`BuildRouteGroundRestPoint` 和 `BuildPlatformLandingAccents` 生成的子物件必须带 `NoCollision`，冷光/脚印/苔痕必须额外带 `NoYellowPlate`，并保持低 alpha；攀爬/符文路线这类半空提示必须至少抬到 `GroundY + 6.70f` 以上，视觉上和主地板、低台、主角头顶拉开，不能贴在玩家脚下像残留贴片；平台间的 `RouteDressing_PlatformGapMossEcho_NoCollision_*`、`RouteDressing_PlatformGapStoneEcho_NoCollision_*` 和 `RouteDressing_PlatformGapUnderShade_NoCollision_*` 必须整体高于平台顶面约 `.46f`，只作为半空路线回声；相邻平台间允许少量 `RouteDressing_PlatformJumpArcLeaf_NoCollision_*` 叶片形成跳跃弧线，但必须高于平台顶面约 `.64f` 并带更明确弧高，只能是低透明环境叶片，不得变成常驻横线、箭头、金币串、黄色板或碰撞体；平台顶面的 `RouteDressing_PlatformLandingToeL/R_NoCollision_*` 只能是很小的中心落脚提示，不得变成黄色板、框线或碰撞体。低位碎石和休息点才允许贴地。禁止恢复 `_RootMark`、`_StoneA`、`_ColdGlow`、`_RopeA`、`_Crystal_`、`RouteDressing_PlatformFootGrass_` 这类无后缀子对象名，避免清理器漏扫和玩家误判为可踩/可挡/可点的东西。
- 前景装饰只能服务关卡氛围，不能遮挡战斗阅读：`BuildForegroundSceneDressing` 里的围栏、蘑菇、草丛、石柱和藤帘必须全部用 `NoCollision` 命名，并通过 `AddForegroundProp(..., alpha)` 统一限制透明度到 `.12f-.52f`；石柱和藤帘必须低排序、缩小并后移，不能恢复 `MossStonePillar_MidBack` 的 `.86x1.72` 大尺寸或 `VineCurtain_ArchBlend` 的 `1.20x1.85` 高遮挡贴图。前景贴图禁止 `Color.white` 原样全亮显示，必须用偏森林色的环境融合色，避免像贴纸压在角色、敌人、宝箱和右手按钮上。
- 可踩平台必须用图形边界读出来但不能有框感：`BuildPlatformReadabilityEdges` 为每个平台只添加 `PlatformWalkableSoftTop_NoFrame` 和 `PlatformContactAo_SoftThin`，让玩家能从中部软顶边和落点预测判断可踩区域；顶边只允许平台中部短高光，宽约 `Mathf.Clamp(size.x * .22f, .18f, .42f)`、高 `.0025f`、alpha `.006f`，接触 AO 约 `size.x*.16 x .005f`、alpha `.014f`。生成平台贴图也必须由 `BuildPlatformArtSolidUnderside` 补出 `AdventureArtFullSolidBacking`、`AdventureArtHiddenDirtCore`、`AdventureArtDeepStoneFace_NoBackgroundLeak` 和 `AdventureArtBottomNoLeakSeal_BrokenShort`，让主角脚下是完整草皮、土层和石面，而不是透明背景或悬浮贴片；根部阴影和底部封边必须使用 `AdventureArtHiddenRootBlend_BrokenShort` / `AdventureArtRootShadowBlend_BrokenShort` 这种短碎低透明层，不能变成全宽横线、一整块黑色矩形背板或贴片硬边；补层必须用浅土石色和 `AdventureArtMossyStoneFaceBreakup` 打散边缘。`BuildPlatformLandingLanguage` 还必须给每个平台补中心踏面、苔藓唇边、脚底 AO、左右碎石和短藤根，让远景一眼看出可落脚中心和实心厚度；`BuildPlatformStageModuleSilhouette` 还要追加模块化土石核心、顶面草垫、石带、底部碎块和左右端面，`BuildPlatformAdventurePlayableBlockFace` 必须再补连续草冠、土石前脸、下层石肚、底部遮漏、端面和短根须，让平台像完整横版关卡块，而不是薄贴片。低空可踩碎台阶必须经由 `PlatformRouteAirLift = .62f` 统一抬升，顶面必须明显抬离主地板，静态验收最低净空不得低于约 `2.40` 世界单位，避免空中物件贴着地面像没扣干净的残片；抬高后的平台必须通过 `BuildPlatformSceneAnchors` 补可见但低透明的 `AdventurePlatformStoneSupportPillar`、`AdventurePlatformBrokenPierStone`、`AdventurePlatformBackfillBrokenStone`、藤根和接地 AO，让平台像由遗迹/树根托住，而不是漂浮薄片。所有这些补层只参与视觉，不新增碰撞体，避免为了实心感重新制造空气墙。禁止恢复中心 tick、左右边界针、ledge pin、完整描边框或全平台长横线。空中时 `HeroLandingPredictor` 必须先通过 `PredictedLandingX` 根据摇杆/键盘水平输入和下落速度做短距离前向预测，再通过 `PredictedLandingPlatform` 判断当前会落在地面还是平台；落在平台时用平台宽度压缩/扩展 `HeroLandingPredictorEdgeLine`，地面落点使用更淡的默认宽线，落地、弹窗或标题页时隐藏。
- 平台实心感必须进一步接近横版童话关卡块：每个可踩平台都必须先执行 `BuildPlatformSolidFooting`，用 `AdventureSolidDirtCore`、`AdventureSolidWalkableGrassCap` 和 `AdventureSolidStoneMass` `AdventureMosaicRoundedStoneBlock_NoCollision_*`、`AdventureMosaicMossInStoneCrevice_NoCollision_*`、`AdventureMosaicReadableGrassCrown_NoCollision` 和左右草根端面，形成 Q 版石砖分面；即使已经有 AI 平台贴图，也必须通过 `BuildPlatformAdventureCartoonCrossSection` / `BuildPlatformStageModuleSilhouette` 保留足够可见的土层、石肚、草冠和端面补层，不能只靠半透明薄贴片表达可踩面。每个平台还必须通过 `BuildPlatformReadableWalkableCap` 增加 `AdventureReadableWalkableGrassCap_NoCollision`、亮边、根垫、土层唇、脚底 AO、石砖面和短草叶，并再执行 `BuildPlatformAdventureKingLandingLanguage` 叠加 `.085f/.12f/.16f` 级别的可读度；最终层也只能是视觉块，不能新增碰撞、空气墙、完整描边框或粗黑横线。

- 平台之间的半空装饰也必须和脚底层拉开：`RouteDressing_PlatformGapMossEcho_NoCollision_*` / `RouteDressing_PlatformGapStoneEcho_NoCollision_*` / `RouteDressing_PlatformGapUnderShade_NoCollision_*` 的中心高度必须是平台顶面插值后约 `.74f`，`RouteDressing_PlatformJumpArcLeaf_NoCollision_*` 的基础高度约 `.98f` 且弧高约 `.30f`；它们只作为跳跃路径上方的环境叶片/苔痕，不能贴近主角脚底、不能像残留横线、不能成为可踩平台或空气墙。
- 世界层门牌和小宝箱文字必须按距离收纳：普通远处房间门牌隐藏文字，只保留低透明图标；商店/精英/Boss 远处只给弱特殊标记，`RoomGateSpecialBadgeNearDistance` 内或当前房非战斗状态才显示房型短字；`RoomGateStateTextNearDistance` 内且非战斗才显示状态，当前房战斗中隐藏“战斗中/词缀名”等门牌字，由顶部目标栏表达清敌目标。平台宝箱文字由 `UpdatePlatformRewardGuideDeclutter` 控制，生成时初始 text/alpha 必须为 0；战斗中不显示“小宝箱/奖励箱/宝箱可选”文字，只保留箱体轮廓、锁孔和接触阴影；清房后距离约 `2.6f` 内才显示“小宝箱/奖励箱”，透明度约 `.58f`。`UpdatePlatformRouteHint` 只在清房后约 `PlatformRouteHintClearedDistance` 内提示“箱 右3m · 跳上打箱 / 攻击开箱 / 顺路开箱”这类短 token，屏外宝箱不能常驻刷提示，并通过 `FitHudText(platformRouteHintText, 18, 26)` 自适应，不能写成长句挤到底部。
- 房间门的透明锚点必须显式使用 `RoomGateInvisible*_NoVisualPlate` 命名，不能恢复 `RoomGateFrame_` / `RoomGatePillar_` / `RoomGateDoor_` 这类容易在调色或导入异常时读成残留框的对象名；门的可见状态只由近距离低透明图标、目标栏和短 Notice 表达。
- 小宝箱必须有真正的箱体轮廓且不能遮挡视野：平台宝箱约 `PlatformRuneChestVisualScale = .46f`，地面宝箱约 `GroundRuneChestVisualScale = .64f`，目标奖励箱只额外增加约 `.04f`；`BuildRuneChestReadableSilhouette` 必须生成 `ChestReadableOuterEdge`、`ChestReadableKeyhole` 和 `ChestReadableFloorAo`，并由 `BuildRuneChestCompactReadabilityDetails` 增加侧扣、铰链和小脚垫，保证玩家远景能凭形状看出是可打宝箱，而不是漂浮 UI 图标或大光标。
- `ThreatAlertBackplate` 必须提供固定暗红/黑底，不能跟随雷阵、金币或奖励色变成黄色/橙色背景板；舒适低闪档下降低透明度但保留可读性。
- 预告牌是补充层，仍必须保留 `AddDangerPattern`、`AddDangerPatternGlyph`、倒计时、头顶意图、方向提示和世界短字；伤害、瞄准/雷击、毒素必须分别有 `!!`、“瞄”和“毒”等非颜色识别信号。

## 预输入反馈

- `AttackInputBufferDuration`、`JumpInputBufferDuration`、`DodgeInputBufferDuration` 是触屏容错窗口，不是自动战斗；只在玩家主动提前按键后短暂保留输入。
- 右手战斗按钮必须按横版动作手游的拇指优先级排列：`Attack` 最大并最靠右下但必须完整显示，`Jump` 靠近攻击键左上侧，`Dodge` 位于攻击键左上，正式触控 HUD 只显示 `Skill1` 剑气一个核心技能，隐藏 `Skill2` / `Skill3` / `Skill4` 以降低画面和操作负担；隐藏技能只能作为内部扩展资产保留，不能绑定触摸反馈、技能预览、拖动微调或正式布局坐标。`RuneOpen` 放在单技能上方偏内侧，作为战斗间隙/可交互 SLOT 宝箱按钮；默认布局必须使用 `Attack (-36,188)`、`Jump (-226,218)`、`Dodge (-178,356)`、`Skill1 (-100,462)`、`RuneOpen (-198,536)`，紧凑布局使用 `Attack (-34,178)`、`Jump (-218,202)`、`Dodge (-170,332)`、`Skill1 (-96,438)`、`RuneOpen (-190,512)`，并通过 `ControlReachOffsetForButton` 按按钮类别缩放右手偏移，不能让跳跃/闪避因为整组右移而压到攻击键下方，也不能把技能或启封键散到屏幕中间遮挡地图。
- `JumpInputBufferDuration` 同时负责落地前预输入和空中二段跳输入；跳跃按钮自身用 `AttachJumpButtonEvents` 记录 `touchJumpHeld`，松手时由 `CutJumpHeight` 和 `JumpCutVelocityMultiplier` 控制短按低跳。`airJumpsRemaining` 落地后重置为 `MaxAirJumps`，空中最多消费一次；正式 HUD 不显示跳跃预输入微文案，避免按钮区堆字。
- 横版推进必须支持轻量疾跑：键盘在 `QuickRunInputWindow = .24f` 内双击同一方向可触发约 `.72s` 快跑，触屏摇杆横向满推超过 `QuickRunJoystickThreshold = .88f` 时持续维持疾跑；速度只乘 `QuickRunSpeedMultiplier = 1.16f`，并继续通过 `IntentAwareMovementRight`、`ApplyGateEdgeSoftReleaseNudge`、`ApplyPlatformEdgeHorizontalEscape`、`NormalizePlayerSupport` 和 `RecoverPlayerIfMovementStuck`，不能绕过房门、平台边缘或防卡逻辑。疾跑期间 `TrackQuickRunRoomUsage` 必须累计 `quickRunTimeThisRun`，给 `ComputeCameraLookAhead` 临时增加 `QuickRunCameraLookAheadBonus = .42f` 的前方视野，并把房间入场时的 `roomQuickRunStart` 用于疾行评价；疾跑起跳只允许 `QuickRunAirCarryDuration = .34f` 的同向短惯性，输入低于 `QuickRunAirCarryMinInput = .20f`、下拉或反向时立即衰减，落地后只允许 `QuickRunLandingCarryDuration = .28f` 的短续跑，不能变成自动滑翔或落地冲刺穿门；疾跑反馈只允许 `QuickRunStartFootLine_NoYellowPlate`、`QuickRunSpeedTick_NoYellowPlate`、`QuickRunStepDust_NoYellowPlate`、`QuickRunJumpCarryFootLine_NoYellowPlate`、`QuickRunJumpCarryLiftTick_NoYellowPlate`、`QuickRunLandingCarryFootLine_NoYellowPlate` 和 `QuickRunLandingCarryForwardTick_NoYellowPlate` 这类冷色短脚线，进入疾跑时提示一次，持续跑步只按 `QuickRunFootstepInterval = .135f` 出脚步，不生成残影、黄色背景板或长拖尾；`JoystickIntentText` 满推横向时显示“疾跑”。
- 平台落地必须有轻量边缘宽容：`PlatformLandingEdgeAssistX` 只在玩家从平台上方下落、横向输入指向平台内侧、且脚点离左右边缘很近时生效，把 `pos.x` 轻微吸到 `PlatformLandingEdgeSnapInset + PlatformLandingStableEdgeTolerance` 内侧；普通走跳仍只用 `.020f` 基础宽容，疾跑空中惯性期间才允许额外 `QuickRunLandingEdgeAssistBonus = .070f`，且仍必须满足 `crossingTop`，不能从侧面或下方吸上平台。成功时只生成极短的 `PlatformLandingEdgeAssistPin_NoYellowPlate`，不能表现成自动爬墙、空气墙、长横线或黄色落点板。
- 玩家脱困只能回到当前脚下或更低的稳定支撑面，`StableSupportYAtX(x, currentY)` 必须过滤高于当前脚点的头顶平台，避免自动恢复把角色吸到上层平台底部。角色如果因刷新、厚地板美术或平台边缘被放到顶面下方，`NormalizePlayerSupport` 必须用 `PlatformSupportUnstickTolerance` 把脚点顶回最近可站面，并由 `movement-unstuck-audit` 的 `platform-unstick-*` 样例验证，不能出现“卡在地板上”的手感；站在平台边缘持续往外走时，`ApplyPlatformEdgeHorizontalEscape` 必须用 `CurrentStandingPlatformAt(new Vector3(beforeX, pos.y, pos.z), PlatformSupportUnstickTolerance + PlatformEdgeEscapeSupportToleranceBonus)` 判定当前支撑，并通过 `Mathf.Max(movementRight, IntentAwareMovementRight(beforeX, horizontalInput))` 放宽开放路线旧边界，再用 `PlatformEdgeHorizontalEscapeNudge` 当帧推出平台边缘，`platform-leave-*` 必须证明左右边缘都不会黏住；这个额外容错只能用于平台边缘离开，不能改动普通落地吸附或把玩家吸到头顶平台。当玩家持续按方向但坐标不动时，`RecoverPlayerIfMovementStuck` 必须在约 `.018s` 内调用 `TryFindMovementStuckRecovery`，先通过 `TryRecoverOffPlatformEdge` 使用 `PlatformEdgeStuckRecoveryOutset` 沿输入方向把平台边缘卡点释放到外侧同层或更低支撑，再沿输入方向用约 `10` 个探测点查找同层或更低稳定支撑，只有前进距离达到 `MovementStuckRecoverMinAdvance` 才修正坐标，避免“角色有跑步动作但位置出不去”，也避免把玩家吸到头顶平台。若当前没有真实锁门，开放路线的旧门框、旧 segment 或视觉厚地板卡点必须先经 `ApplyGateEdgeSoftReleaseNudge` 做门边当帧软释放，再经 `ApplyOpenRouteIntentUnstickNudge` 做 `OpenRouteIntentSoftNudge` 小位移确认，再由 `OpenRouteStuckRecoveryRight` 扩展探测范围；如果玩家已经在门边持续右推但仍然不前进，`RecoverPlayerIfMovementStuck` 必须先识别 `recoverableOpenRouteRightLimit`，再经 `ShouldForceOpenRouteOnRightIntent` / `OpenRouteRightIntentFallback` 打开到下一开放边界，不能因为处在水平限制而提前返回。`movement-unstuck-audit` 必须输出 `gate-edge-soft-release`、`open-route-stuck-widen`、`open-route-right-intent-*` 和 `open-route-intent-soft-nudge`，证明玩家不会在可通行路线里原地跑。
- 平台下穿必须支持“下方向 + 跳跃”：`ShouldDropThroughPlatform` 只在玩家站在当前平台顶面且 `DownInputHeldForDropThrough` 为真时返回当前 `CurrentStandingPlatform`，`DropThroughPlatform` 只忽略 `platformDropThroughTarget` 一小段 `PlatformDropThroughDuration`，不能穿地面、穿房间推进锁或从侧面吸上平台；反馈只能用 `PlatformDropThroughFootLine_NoYellowPlate` / `PlatformDropThroughDownTick_NoYellowPlate` 冷色短线。
- `AttachSkillPreviewEvents` 覆盖 4 个技能按钮：PointerDown 只显示 `SkillAimPreview`，不扣 MP、不进冷却、不造成伤害；前方技能用 `SkillAimPreviewGuideLine_NoPlate`、`SkillAimPreviewEdgeLine`、`SkillAimPreviewMidTick_NoPlate` 和 `SkillAimPreviewFootAnchor` 这种细轨迹线标方向，前向预览主线 alpha 约 `.095f`、高度约 `.016f`，范围技能用 `SkillAimPreviewThinAreaLine`、`SkillAimPreviewLeftBoundary`、`SkillAimPreviewRightBoundary` 标边界，范围线高度约 `.020f`；预览期间禁止 `SkillAimPreviewLabel` 这种世界文字，禁止大面积半透明圆/块遮住主角、平台和敌人；PointerUp/PointerExit、释放成功、打开弹窗或输入锁定后必须隐藏。

- 平台跳跃时，短按跳跃应明显低于长按跳跃；离地后第一次提前按跳能触发二段跳，用于修正高台/断桥落点；二段跳用完后，落地前提前按跳仍显示“落地”并在落地瞬间执行，松开跳跃不能取消已经落地完成的状态。
- 按住技能时，剑气/炎弹显示前方轨迹条，冰环/雷击显示范围圈；预览存在期间移动或转身应同步更新，冷却中和魔力不足时不显示可释放预览。
- 快速轻点攻击、跳跃、闪避、技能和 `SLOT` 键时，应立即看到外圈回弹；空按攻击只有按下反馈和出刀刀光，不显示 `HitConfirmText`。
- 连段中 `AttackRhythmWindowFill` 会随剩余窗口缩短；第二段切换为青蓝色强调破势窗口，打开弹窗或连段结束后隐藏，正式 HUD 不显示节奏小字。
- 二连后进入第三段可接窗口时，攻击按钮必须短暂显示更明确的“破势可接 / 可接”节奏反馈：`ShowBreakReadyCueOnce` 只在 `attackCooldown <= .055f`、`comboTimer > .12f` 且控制未锁定时触发，生成 `AttackBreakReadySnapTick`、`AttackBreakReadyRing` 和脚底 `AttackBreakReadyFootSnap_NoTexturePlate`，其中可接环约 `208x208`、alpha `.060`，脚底提示约 `.42f x .012f`、alpha `.070`，并由 `attackBreakReadyCueCooldown` 节流。该反馈用于让触屏玩家知道第三下可以按，不能变成世界层大字、黄色板或持续闪烁。
- `ComboMilestoneText` 只在 6/12/20 连击阈值突破时短暂出现，文案只能是“连斩 / 狂热 / 极限连击”这类短标签，不能写“保持输出/技能接续/打满三段”长句，不能常驻挤占右上 HUD；连击断掉后 `comboMilestoneLevel` 重置，下次重新达到阈值才再次提示。
